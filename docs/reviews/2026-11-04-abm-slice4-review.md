**For the author on A2.** Per-agent `pledged` is necessary but not sufficient for Mackie. Necessary: with one shared atom the first pledger lifts R5 for every family, so the sanction cannot discriminate pledgers from non-pledgers and `material` alone collapses the practice. Not sufficient: even with per-family `pledged`, the pledge pays the default 1.0 and is lawful, so a third of families pledge at step 0 by tie-break, and the suitor side (R5/R6) is never exercised because suitors' actions carry no payoff consequence for families; the assurance that drives Mackie's flip is the marriage prospect, which in this encoding is only the R3 charge. So decide A2 for pledge fluents, but also give the pledge a cost (or 0 payoff) and set `initial_practice: bind`; otherwise (a) will still be decided by ties at step 0.
