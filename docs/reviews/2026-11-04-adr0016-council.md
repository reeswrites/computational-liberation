## Correctness and scope seats

Read-only. Severity: [red] changes a verdict or test; [amber] needs a stated criterion; [green] no change.

1. **[red] The `narrowed` relabel contradicts the ADR's own layer table and the glossary.** The table puts Erosion at lowest layer 2 ("practice drifts back"), but the MWPA run reports it fired at layer 1 (`plans/backtest-mwpa.md:70`, `backlash reachable`), and `docs/interpreting-results.md:59` says "layer 1 can only fire Capture and Cosmetic". As encoded (`_gen_institutions.py:599-600`: +R17 court may construe_narrowly, +R18 R1 reinstated) the branch adds rules, which is the glossary's definition of backlash (`docs/glossary.md:18`, "a rule added to reinforce the existing bundle"), not drift of practice. Either the branch is Backlash (rule added) and the relabel is wrong, or Erosion's lowest layer is 1 when encoded as a court power. Recommend: revert `narrowed` to BL, or amend the table to "Erosion: 1 when encoded as a construing power, 2 as practice drift", and align `glossary.md:18` with the ADR's "active reaction" wording.
2. **[red] The restated Section 4 test no longer partitions outcomes.** Original (`backtest-mwpa.md:52`): pass DT/BL, fail DI/RB first; four modes, exhaustive. Restated (`:85`): pass Capture/Erosion, fail DI/RB first; seven other modes top-ranked are neither. Given finding 1 and `interpreting-results.md:59`, "Capture top-ranked at 1839-50" is also near-guaranteed at layer 1 if a ranking ever existed. Not easier to pass today (outcome stays inconclusive, no ranking), but looser once layer 2 ranks. Recommend: "fail if any mode other than Capture (1839-50) or Erosion/Backlash (1860-80) ranks first".
3. **[amber] Capture's criterion depends on an unstated "for whom".** `backtest-mwpa.md:45` and `_gen_institutions.py:629-632` describe the 1839-50 wave as debtor relief (Khan); a husband sheltering assets is then the statute's intended use, not "a party the change was not for" (`0016:28`). Capture is only a failure relative to the liberation reading. Recommend: the ADR states that "for" means the preregistered liberated role, and each preregistration names it.
4. **[amber] Axes are not orthogonal by any stated criterion.** Gig economy fits Dark twin ("capital rebundles") and Capture ("a party not for gains new power"); the ADR separates them by example only. A pre-data criterion exists and should be written: Rule-axis modes are reachable from the rule set as written (no new actor, no new rules); Who-pays modes need a new actor or institution; Time modes need dynamics. Cosmetic is correctly Rule (an iso property of the delta). `double_burden` fits neither DI nor Perverse incentive (nothing rewards undermining; R3 is simply untouched): it is partial unbundling, not a mode. Recommend: label it "partial reform (no mode)" or keep DI with the note; drop the Perverse-incentive suggestion (`0016:48`).
5. **[amber] Lowest-layer column: three entries lack a detection criterion or sit on the wrong layer.** Backlash=2: layer 2 agents adopt actions, never add rules (`plans/layer2-abm.md:35-56`); active reaction is 3, or 1 if encoded as a branch. Enforcement decay=2 "needs A4", but A4 (`0015:13`) makes sanction weight a swept constant, nothing makes `or_else` stop firing over time. Dead letter=2: "never crosses threshold" over a sweep is undefined (some parameter points always fail, `0015:19`). Recommend one line per layer-2 mode stating the sweep-level criterion.
