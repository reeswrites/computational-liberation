At 2/role nobody assigns, P goes false at step 0 and from step 1 every metapelet is an unavoidable breach (None and neglect both leave P false, model.py:313-315), still counted 1.0 in `breaches`. The rate conflates chosen and forced breach. Recommend: report per-step unavoidable counts alongside `breaches`, or exclude forced breaches from the rate (and from sanction, since A4 says breach is a choice).
4. **[amber] Diagnostic counters double-count on reads between steps.** `_diagnose` runs inside `_readings` (model.py:252) and `step` clears the cache twice (343, 349), so any `available_for`/`state_obligations_for` call between steps re-runs it at the same `self.t`. Caching per state is otherwise correct and `state_breaches` passes `frozenset([a])` alone (312) as A8 requires. Fix: key counters by (rule, t) or run `_diagnose` from `step`.
