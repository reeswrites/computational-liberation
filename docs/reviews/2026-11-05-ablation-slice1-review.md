# Correctness review: ablation slice 1 (uncommitted, philosophy-engine) — 2026-11-05

Fresh agent, correctness seat (ADR 0014); not the builder. Read-only; ran tests/test_rules_ablate.py (9 pass) and `phil rules ablate` on kibbutz and ectogenesis at k=6.

1. **[red] The "permission removed" label is false when the deleted `may` is the only may/must on its action.** rules_lower.py:888 treats an action no may/must rule names as unregulated: "always enabled", and it fires freely. Deleting kibbutz R1 (sole `may assign`) therefore opens assignment to everyone (R2 still bars male), so care_assigned_by_sex persists>fails is a permission widened, not removed. Ectogenesis R4 is the other case: R5 `must provide_care` still regulates the action, so there the deletion really does remove the permission. Fix: per `may` deletion, record `deregulated` (no remaining may/must on the aim's action), label it so, and decide whether deregulating deletions count toward load or are listed apart (decision 3 covers neither).
2. **[red] Derived powers flip for the same reason.** `(enabled X)` is false for an unregulated action (rules_lower.py:617), so deleting kibbutz R6 makes can_sanction false while `reprimand` still fires freely. The care_and_sanction_same_role violated>holds_to_k flip is the power vanishing as an artefact of deregulation. Real loader path (item 5) is fine, since derived fluents are re-lowered from the remaining rules, but the semantics need the `deregulated` flag from 1.
3. **[amber] Orphaned `or_else` (judgment 1).** Under the default `compliance=strict`, `or_else` is ignored (rules_lower.py:910), so orphaning changes nothing and load is not inflated. Under `sanctioned` a cleared reference turns a soft must_not hard, which does inflate. The CLI prints no orphan column. Fix: show `orphaned_or_else` in the table and run sanctioned mode only with it visible.
4. **[green] Unknown/error handling (judgment 2).** `effective_verdict` counts `open` only for check=reachable with the "not 'safe'" reason, which `check_reachable` emits only when z3 gave no reason. Real bounded-unreachable stays counted; timeouts, consistency-unknown, invariant/persists open and error go to `uncounted`. Residual: a z3 unknown with an empty reason_unknown() would be counted. Fix: key on a flag from `_check`, not message text.
5. **[amber] Flips are unsigned.** Load counts persists>fails and reachable>open the same as the reverse, and R1 and R4 mix freedom-up with freedom-down. Fix: store direction (liberating / binding) per flip and report both counts.
6. **[amber] `female_parent_care_persists` cannot be carried by R5.** On ectogenesis it reads `persists` before and after deleting R5 (checked): care once given is never withdrawn, so the persists shape ignores whether it was forced. R5 reads load 0 by construction, so the T3 expectation is untestable, not refuted. Judgment 3: the exists guard prevents pre-birth vacuity, but the property is vacuous with respect to R5. Fix: an invariant-shaped companion ("a female parent exists who does not provide care" reachable), preregistered before rerun. It is applicable on only cps, ectogenesis and gestational-surrogacy.
7. **[amber] Check kind for unexpected properties (judgment 4).** `check_kinds` takes the majority of other entries' hand-written expectations, else a name-suffix rule. This is a hand input. It is deterministic and visible in `expected_properties`, but flips depend on it. Fix: print the chosen check per property in the output.
8. **[amber] Weak metamorphic tests (judgment 6).** (a) never asserts a non-zero base load, so it would pass if loads were always 0 (test_basic_flip alone catches that). (c) asserts `>= 0`, a tautology. (e) only checks the empty case, so it would pass if `k_disagreement` were always empty. (b) is adequate, since it compares against a base with load 1. No test covers orphaning, a deregulating `may`, z3 unknown, or a derived-power fixture. Fix: add a deregulation fixture (item 1), a k-disagreement positive, and a non-zero assertion in (a).
